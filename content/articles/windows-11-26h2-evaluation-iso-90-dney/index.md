Microsoft открыла публичное скачивание ISO-образов Windows 11 версии 26H2, их может получить любой желающий, без программы Insider. Но это не тот дистрибутив, которого ждали домашние пользователи. В Evaluation Center лежат ознакомительные сборки Windows 11 Enterprise Evaluation: 90 дней работы, одиннадцать языков без русского и лицензионная структура, которая не позволяет активировать систему ни ключом, ни цифровой лицензией.

Коротко, что можно и чего нельзя:

| Вопрос | Ответ |
|---|---|
| Скачать и установить | Да, бесплатно, регистрация на сайте Microsoft |
| Русский язык | Ставится языковым пакетом за 10 минут |
| Продлить пробный период | Да, до 270 дней командой `slmgr /rearm` |
| Активировать ключом | Нет, никогда: ни своим, ни KMS |
| Конвертировать в полную версию | Механизм существует, но для свежей 26H2 пока упирается в номера сборок |

Разберём каждый пункт: что именно выложила Microsoft, как устроен таймер ознакомительной версии и что реально можно сделать с этой системой сегодня.

## Что сейчас лежит в Evaluation Center

21 сентября Microsoft опубликовала ISO-образы Windows 11 версии 26H2 со сборкой **26300.9457**, в них включено накопительное обновление KB5129195. Образы собирались 13 сентября 2026 года, и это уже не Release Preview: в августе тестовые ISO имели сборку 26300.9278.

Все образы выпущены в редакции Enterprise Evaluation, что видно прямо из имени файла:

```
26300.9457.260913-1737.26h2_ge_release_svc_refresh_CLIENTENTERPRISEEVAL_OEMRET_x64FRE_en-us.iso
```

Редакцию выдаёт фрагмент `CLIENTENTERPRISEEVAL` в имени файла. Если он есть, перед вами ознакомительная версия с обратным отсчётом, а не обычная Windows.

Языков одиннадцать, все x64: en-us, en-gb, de-de, fr-fr, es-es, it-it, pt-br, ja-jp, ko-kr, zh-cn, zh-tw. Русского нет. Для скачивания нужна регистрация в Evaluation Center; ключ продукта при установке не запрашивается: система активируется сама при первом подключении к интернету и начинает отсчёт 90 дней.

Важный контекст: Media Creation Tool по-прежнему раздаёт Windows 11 25H2 со сборкой 26200.9457. Официальных полных образов 26H2, обычных, а не ознакомительных, пока нет ни в MCT, ни на странице загрузки Windows 11. Переход с 25H2 на 26H2 выполняется пакетом включения функций [KB5121794](/articles/windows-11-26h2-kb5121794-obnovlenie/), но это обновление уже установленной системы, а не новый образ.

Ещё одна деталь из Installation Guidelines на странице Evaluation Center: при установке потребуется вход в аккаунт Microsoft. Возможность создать локальную учётную запись обещают «к моменту финального выпуска».

## Почему ознакомительную Windows нельзя активировать

Evaluation нельзя назвать «недоактивированной» Windows: это отдельная лицензионная конструкция. Пробный период вшит в лицензионные файлы образа, и после его истечения система не принимает ни розничный ключ, ни цифровую лицензию, ни активацию через KMS. В документации проекта Microsoft Activation Scripts (MAS) это сформулировано прямо: «you can not permanently activate it with your genuine key, digital license, KMS, etc.».

Представитель Microsoft в Q&A в ноябре 2025 года выразился ещё жёстче: ознакомительная редакция «зашита» таймером на 90 дней, конвертация в полную версию не поддерживается, единственный официальный выход: переустановка с правильного образа.

Что происходит после истечения 90 дней, описано в официальных Installation Guidelines:

- фон рабочего стола становится чёрным;
- появляется постоянное уведомление о неподлинности системы;
- **компьютер выключается каждый час**.

Последний пункт не опечатка. Это не водяной знак, с которым можно жить месяцами: через час работы система завершает сеанс. Проверить остаток пробного периода можно в `winver` (там же видно редакцию «Windows 11 Enterprise Evaluation») или командой `slmgr /dlv`.

## Шаг 1. Русский язык за 10 минут

Отсутствие русского ISO не означает, что система останется английской. Языковой пакет ставится из Центра обновления и полностью переводит интерфейс. Порядок действий для образа en-us:

1. `Win + I` → **Time & language** → **Language & region**.
2. В блоке **Preferred languages** нажмите кнопку **Add a language**.
3. Найти **Russian**, отметить **Set as my Windows display language**, нажать **Install**.
4. После загрузки пакета нажмите **Sign out** и войдите снова.

Интерфейс станет русским, но базовым языком системы останется en-us: язык образа изменить нельзя. Это имеет практическое следствие: если позже вы решите обновлять эту систему in-place (например, при конвертации в полную версию), ISO понадобится тоже en-us. Установка «поверх» образа другого языка лишает возможности сохранить программы, и ниже будет понятно почему.

## Шаг 2. Продление до 270 дней

Ознакомительный период официально продлевается: механизм rearm встроен в саму Windows. Команда выполняется в командной строке от имени администратора:

```
slmgr /rearm
```

После выполнения нужна перезагрузка. Для клиентских редакций Windows 10/11 Enterprise Evaluation доступно **два продления по 90 дней**, суммарно до 270 дней работы. Точный остаток показывает `slmgr /dlv`, строка **Remaining Windows rearm count**.

Два уточнения. Первое: продлевать можно и после истечения срока: MAS документирует, что `slmgr /rearm` срабатывает на уже просроченной системе. Второе: не путайте с Windows Server, у серверов свои правила: продление даёт 180 дней, а допустимое количество продлений зависит от версии. Серверные советы на клиентской Windows не работают.

Существуют и способы сбросить таймер в любое время: через утилиту TSforge из того же MAS или очистку ключей реестра `HKLM\SYSTEM\WPA`. Инструкций здесь не будет: такое обнуление пробного периода нарушает лицензионные ограничения со всеми вытекающими рисками. Почему таким инструментам не стоит доверять, разобрано в статье про [KMS Auto и старые способы активации](/articles/kms-auto-windows-10-11-staryj-sposob-aktivacii/).

## Шаг 3. Конвертация в полную версию: механизм есть, сборок нет

Самый обсуждаемый вопрос: можно ли превратить Enterprise Evaluation в нормальную Windows без переустановки. Здесь сталкиваются два утверждения. Microsoft говорит «нет». MAS документирует рабочий обходной путь: in-place upgrade с полного ISO и правкой реестра. Формально правы оба, и вот почему.

Механизм из документации MAS выглядит так:

1. В реестре меняется идентификатор редакции:
   ```
   reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion" /v EditionID /d EnterpriseS /f
   ```
   Для Windows 11 на неподдерживаемом железе используйте `IoTEnterpriseS`.
2. Монтируется ISO **полной** редакции Windows 11 Enterprise LTSC той же языковой базы и архитектуры.
3. Запускается `setup.exe`, на финальном экране обязательно должно быть доступно **«Сохранить личные файлы и приложения»**.

После такого обновления система перестаёт быть ознакомительной: таймер исчезает, остаётся обычная Windows Enterprise LTSC, которую можно активировать легально полученной лицензией. Есть и второй путь (GAC): правка `EditionID` в `Enterprise` и установка с обычного полного ISO, при запросе ключа используется публичный GVLK-ключ Enterprise `NPPR9-FWDCX-D2C8J-H872K-2YT43` из документации Microsoft.

Теперь арифметика сборок, которая ломает весь фокус для свежей 26H2:

| Что | Сборка |
|---|---|
| Evaluation 26H2 (то, что скачиваем сейчас) | 26300 |
| Полные ISO LTSC 2024 (включая ru-ru) | 26100 |
| Полные ISO из Media Creation Tool (25H2) | 26200 |

Опция «Сохранить личные файлы и приложения» в установщике доступна только когда сборка ISO не ниже текущей и язык совпадает. Установка 26100 или 26200 поверх 26300 означает даунгрейд: установщик предложит в лучшем случае сохранить файлы, но не программы. Метод MAS штатно работает, когда eval и полный ISO на одной сборке, например 24H2 Eval (26100) и LTSC 2024 (26100).

Для 26H2 конвертация станет реальной, когда Microsoft выложит полные ISO со сборкой 26300: в Media Creation Tool или на странице загрузки. Тогда GAC-путь (EditionID → Enterprise + in-place upgrade) отработает с сохранением программ. Точную дату релиза Microsoft не называла; из официальных формулировок следует, что общий выпуск 26H2 ожидается до конца 2026 года.

Кстати, о серверах: Windows Server Evaluation конвертируется в полную версию официально, через `DISM /Online /Set-Edition` или опцию change edition в MAS. Запрет касается только клиентских редакций.

## Три реальных сценария

**Хочу 26H2 прямо сейчас.** Ставите eval-образ, добавляете русский языковой пакет, при приближении срока выполните `slmgr /rearm`. 270 дней с запасом перекрывают время до появления полных ISO 26300, после чего система конвертируется in-place. Минус сценария: всё это время у вас Enterprise Evaluation с почасовым выключением в случае, если забыть о таймере.

**Хочу полную русскую Windows прямо сейчас.** Официальные образы Windows 11 25H2 русский язык содержат: на странице загрузки Microsoft доступен мультиязычный ISO; полной 26H2 пока не существует. Тем, кто понимает зачем, подойдёт Windows 11 Enterprise LTSC 2024 (сборка 26100.1742): полные ISO есть на всех языках, включая ru-ru. Но у LTSC своя специфика: без предустановленного Store и с редкими функциональными обновлениями.

**Не хочу связываться с eval.** Самый спокойный путь: остаться на 25H2 и дождаться 26H2 через Windows Update или [пакет KB5121794](/articles/windows-11-26h2-kb5121794-obnovlenie/). А если нужен чистый образ для установки с нуля, вот [проверенный способ скачать оригинальный ISO с серверов Microsoft](/articles/skachat-windows-original-iso-microsoft/) без торрентов и сборок.

## Чего делать не стоит

**Подмена лицензионных файлов.** Встречается совет «вживить» лицензионные файлы полной Enterprise в установленную eval-систему. MAS разбирает, почему это плохая идея: после такой операции ломаются `dism /online /Get-CurrentEdition` и `/Get-TargetEditions`, лицензионные файлы перестают получать исправления через Windows Update (а Microsoft правит через них политики: например, так в своё время включалась поддержка KMS и Sandbox в IoT Enterprise LTSC), плюс отсутствуют пакеты редакции с недокументированными побочными эффектами.

**«Вечные» активаторы.** Отдельная категория решений обещает активировать eval-версию навсегда. Это невозможно по устройству лицензионных файлов: такие «активаторы» в лучшем случае сбрасывают таймер, в худшем приносят в систему то, ради чего писался разбор про KMS Auto.

## Итог

Первые ISO Windows 11 26H2 служат витриной, а не заменой обычной Windows. Ознакомительная версия честно делает свою работу: даёт посмотреть 26H2 до релиза, говорит по-русски после установки языкового пакета и живёт до 270 дней через `slmgr /rearm`. Конвертация в полную версию с сохранением программ для сборки 26300 заработает не раньше, чем появятся полные ISO той же сборки. А до тех пор единственный способ получить постоянную систему без таймера: ставить не eval, а полный дистрибутив.

## FAQ

**Можно ли активировать Windows 11 Enterprise Evaluation ключом или цифровой лицензией?**
Нет. Ознакомительная редакция не активируется за пределами пробного периода ни розничным ключом, ни цифровой лицензией, ни KMS. Таймер заложен в лицензионные файлы образа, и Microsoft подтверждает: поддерживаемый способ перейти на полную версию: переустановка.

**Сколько раз можно продлить 90-дневный период?**
Два раза командой `slmgr /rearm`, суммарно до 270 дней для клиентских редакций. Остаток продлений виден в `slmgr /dlv` (Remaining Windows rearm count). У Windows Server лимиты другие: продление даёт 180 дней, а их количество зависит от версии.

**Работает ли конвертация eval → полная версия через правку EditionID?**
Механизм рабочий, но требует полного ISO со сборкой не ниже текущей и тем же языком. Для 24H2 Eval (26100) он работает с LTSC 2024 (26100). Для 26H2 Eval (26300) полных ISO пока не существует, поэтому конвертация с сохранением приложений сейчас невозможна.

**Почему в ISO Windows 11 26H2 нет русского языка?**
Microsoft собрала ознакомительные образы только для одиннадцати языков, русский в набор не вошёл. Языковой пакет устанавливается из Центра обновления Windows и полностью переводит интерфейс; базовым языком системы при этом остаётся en-us.
