Microsoft экспериментирует с новым подходом к командной строке. Проект **Intelligent Terminal** добавляет ИИ-агентов прямо в интерфейс терминала и позволяет разбирать ошибки, получать подсказки и запускать сложные задачи, не переключаясь между PowerShell, браузером и документацией.

Это не обновление обычного Windows Terminal. Microsoft выпустила отдельное приложение – экспериментальную ветку Windows Terminal с нативной интеграцией ИИ-агентов. Проект имеет открытый исходный код и распространяется отдельно.

## Зачем Microsoft понадобился ИИ в терминале

Командная строка сама по себе проста: ввёл команду, получил результат.

Проблемы начинаются, когда команда возвращает ошибку.

Администратору или разработчику приходится копировать сообщение об ошибке, открывать браузер, искать документацию, читать форумы, возвращаться в терминал и пробовать исправление. Если ошибка сложная, таких переходов может быть десятки.

Intelligent Terminal пытается убрать эту цепочку.

Приложение видит контекст терминала и может передать результат выполнения команды ИИ-агенту. Тот объясняет ошибку и предлагает способ исправления.

Получается своеобразный цикл:

**команда → ошибка → анализ ИИ → исправление → повторная команда.**

Главное здесь не сам чат с нейросетью. Microsoft пытается сделать так, чтобы ИИ понимал, что именно происходит в терминале.

## Это не замена Windows Terminal

Важный момент: Microsoft не собирается заставлять всех пользователей переходить на Intelligent Terminal.

Проект устанавливается рядом с обычным Windows Terminal и не заменяет его. Если ИИ в командной строке не нужен, существующая конфигурация Windows Terminal продолжает работать как раньше.

По сути, Microsoft получила возможность экспериментировать с агентами отдельно от основного продукта.

И это разумное решение.

Windows Terminal уже давно стал универсальной оболочкой для PowerShell, CMD, WSL и других сред. Добавлять в него экспериментальную агентную систему непосредственно в основной релиз было бы рискованно.

Intelligent Terminal позволяет проверить идею на практике и постепенно менять архитектуру.

## Что появляется в Intelligent Terminal

Главное изменение – специальная панель агента.

Она располагается непосредственно в окне терминала и работает рядом с обычной командной строкой. Агент получает контекст текущей сессии и может работать с командами и их результатами.

Microsoft добавила несколько механизмов взаимодействия.

### Панель агента

Это встроенное окно для общения с ИИ. Его можно открыть рядом с терминалом и использовать для анализа текущей задачи.

Агент при этом не заменяет оболочку. Команды продолжают выполняться в обычном терминале.

### Автоматическое обнаружение ошибок

Если команда завершается ошибкой, Intelligent Terminal способен определить это событие и предложить помощь.

В первой версии такая возможность была ориентирована на PowerShell. В обновлении 0.1.1 Microsoft добавила автоматическое обнаружение ошибок и предложения исправлений для Bash и WSL Bash.

Это уже интереснее обычного чат-бота.

ИИ не нужно каждый раз объяснять: «Я выполнил такую-то команду, получил вот такой текст». Терминал сам знает контекст выполнения.

### Командная палитра

ИИ можно вызывать непосредственно из командной палитры.

Microsoft также добавила специальные команды для обращения к агенту. В актуальной версии появились, например, `/fix` для запроса исправления и `/model` для выбора модели.

### Фоновые задачи

Сложную задачу можно вынести в отдельную сессию, чтобы она не мешала основной работе.

Это особенно полезно, если агент должен выполнить несколько действий подряд.

## Какой ИИ работает внутри

Здесь Intelligent Terminal интереснее, чем может показаться.

Microsoft не привязала приложение намертво к одному сервису.

В качестве агента по умолчанию используется GitHub Copilot, но Intelligent Terminal построен вокруг **Agent Client Protocol (ACP)** – протокола взаимодействия с ИИ-агентами. Поэтому можно подключать совместимые инструменты.

В актуальной документации Microsoft перечисляет GitHub Copilot, Claude Code, OpenAI Codex, Gemini и OpenCode. Кроме того, можно подключить собственный совместимый агент.

Это принципиальное отличие от обычного «ИИ от Microsoft».

Intelligent Terminal фактически становится интерфейсом между командной строкой и агентами разных разработчиков.

## ИИ не выполняет команды молча

Есть важный момент, который легко пропустить.

Intelligent Terminal не должен превращать компьютер в машину, где нейросеть самостоятельно выполняет любые команды без контроля пользователя.

В документации проекта указано, что Intelligent Terminal запрашивает разрешение перед выполнением команд от имени пользователя.

Для системного администратора это особенно важно.

ИИ может ошибиться. А команда вроде удаления каталога или изменения сетевой настройки – это уже не безобидная подсказка.

Поэтому я бы не рекомендовал воспринимать агентный режим как «нажми кнопку и пусть нейросеть сама администрирует сервер».

Это помощник, а не автопилот.

## Что происходит с данными

Есть ещё один важный вопрос – конфиденциальность.

Сам Intelligent Terminal выступает как локальный слой взаимодействия. Он передаёт запросы и контекст выбранному агенту через соответствующий интерфейс и сам не обращается напрямую к облачным API.

Но это не означает, что данные остаются исключительно на компьютере.

Если используется GitHub Copilot, данные обрабатываются инфраструктурой GitHub. При использовании стороннего агента правила зависят уже от его разработчика. Microsoft прямо предупреждает, что защита данных сторонних агентов определяется их собственными условиями.

Поэтому отправлять в ИИ содержимое закрытых конфигурационных файлов, пароли, токены и другую чувствительную информацию без понимания маршрута данных не стоит.

## Как установить Intelligent Terminal

Приложение можно установить через Microsoft Store или WinGet. Microsoft также публикует исходный код и сборки проекта на GitHub.

Через WinGet команда выглядит так:

```powershell
winget install --id Microsoft.IntelligentTerminal -e
```

После установки приложение запускается отдельно от обычного Windows Terminal.

Сейчас проект уже не ограничивается Windows 11: начиная с версии 0.1.1 Microsoft добавила поддержку Windows 10 22H2 и более новых поддерживаемых выпусков.

## Мнение Уловки-32

На мой взгляд, Microsoft движется в правильную сторону.

Но ценность Intelligent Terminal заключается не в том, что теперь можно написать нейросети «исправь ошибку».

Такое уже умеют десятки ИИ-инструментов.

Интереснее другое: **ИИ получает непосредственный контекст работы командной строки**.

Это меняет сам сценарий использования нейросети.

Раньше пользователь должен был объяснить ИИ, что произошло. Теперь приложение может само увидеть команду, её вывод и факт ошибки.

Для разработчика это сокращает количество рутинных действий. Для системного администратора польза ещё очевиднее: многие ошибки в PowerShell, Bash или WSL действительно можно быстро разобрать по тексту вывода.

Но есть и обратная сторона.

Чем больше полномочий получает агент, тем важнее контроль. Нейросеть может правильно определить причину ошибки и неправильно выбрать способ исправления. Особенно опасно это при работе с файловой системой, сетью, службами, реестром и серверной инфраструктурой.

Поэтому я бы использовал Intelligent Terminal как **умного напарника**, а не как автономного администратора.

## Что делать пользователю

Если вы регулярно работаете с PowerShell, Bash или WSL, Intelligent Terminal стоит попробовать.

Это экспериментальный проект, поэтому рассчитывать на идеальную работу пока не стоит. Microsoft сама продолжает активно менять приложение и выпускать исправления.

Обычным пользователям Windows устанавливать его только ради «попробовать ИИ» особого смысла нет.

А вот разработчикам и администраторам есть что тестировать.

Главный вопрос здесь уже не в том, нужен ли ИИ в терминале. Он постепенно туда приходит. Вопрос в другом: **сколько самостоятельности мы готовы ему дать?**
