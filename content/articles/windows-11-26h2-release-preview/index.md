27 августа Microsoft выпустила Windows 11 26H2 в канал Release Preview. Текущая сборка имеет номер **26300.9278**, пакет обновления — **KB5120998**.

До финального релиза Windows 11 26H2 ещё есть время. Microsoft говорит, что общедоступный выпуск состоится позже в 2026 году, но конкретную дату пока не называет.

На первый взгляд новость выглядит привычно: новая версия Windows, новая сборка, очередное обновление. Но технически 26H2 интереснее большинства предыдущих релизов.

Microsoft снова использует **enablement package**. Поэтому переход на 26H2 не стоит воспринимать как очередную переустановку Windows с огромным пакетом изменений.

Дальше — самое интересное.

## Windows 11 26H2 уже частично существует

Microsoft постепенно меняет подход к выпуску Windows.

Раньше крупное обновление можно было представить примерно так: выходит новая версия системы, а вместе с ней пользователь получает большую пачку новых функций.

Теперь часть изменений появляется раньше.

Microsoft использует модель **continuous innovation**. Новые возможности и изменения приходят через обычные ежемесячные обновления. Годовой релиз затем фиксирует следующую версию Windows.

Поэтому к моменту выхода 26H2 многие её возможности пользователи уже могут видеть в своей системе. О том, какие из них Microsoft тестирует заранее, мы разбирали [в статье про скрытые функции 26H2](https://trick32.ru/articles/skrytye-funkcii-windows-11-26h2/).

Microsoft прямо указывает, что Windows 11 24H2, 25H2 и 26H2 используют общую обслуживаемую ветку. Практически это означает: все три версии живут на одной базе компонентов и обновляются одним потоком, а не каждой отдельно. Получают функции эти версии через ту самую модель continuous innovation. Поэтому 26H2 не должна восприниматься как полностью новая Windows.

Это важное изменение в самой логике обновлений.


## Что такое enablement package

Enablement package можно условно представить как переключатель.

Основная часть компонентов Windows уже находится в системе. Некоторые новые возможности могут быть отключены или управляться специальными механизмами.

При переходе на новую версию Microsoft активирует нужные компоненты и переводит систему на соответствующую версию.

Именно поэтому такие обновления обычно проходят заметно быстрее классических крупных feature update.

Microsoft ранее объясняла для 26H2, что переход с общей обслуживаемой ветки выполняется через enablement package и может происходить с одной перезагрузкой.

Это не означает, что любое обновление 26H2 займёт ровно несколько минут. На время установки влияют накопленные обновления, состояние диска, оборудование и конфигурация системы.

Но сама архитектура рассчитана на гораздо менее драматичный переход, чем старые обновления Windows.


## Почему номер сборки выглядит непривычно

Для Windows 11 26H2 Microsoft использует сборку **26300.9278**.

Это важно не только для любителей смотреть `winver`.

Ветка 26H2 отличается от привычных сейчас сборок Windows 11 24H2 и 25H2. При этом Microsoft продолжает связывать эти версии общей моделью обслуживания.

Именно поэтому не стоит делать вывод о масштабе обновления только по номеру сборки.

Больший номер не означает автоматически «в два раза больше новых функций».

Windows давно развивается не только через ежегодный скачок версии.


## Что получат обычные пользователи

Вот здесь ожидания стоит немного охладить.

Если вы ждёте Windows 11, которая после установки 26H2 внезапно изменит интерфейс, меню «Пуск», Проводник и половину системы, — такого сценария Microsoft сейчас не обещает.

Часть изменений уже распространяется отдельными обновлениями. Например, [меню «Пуск» становится настраиваемым](https://trick32.ru/articles/menyu-pusk-windows-11-26h2/), а [панель задач возвращает настройки](https://trick32.ru/articles/taskbar-settings-windows-11/), которые Microsoft раньше вырезала.

Кроме того, некоторые возможности зависят от типа устройства, редакции Windows и политики Microsoft по постепенному развёртыванию функций.

Для корпоративных компьютеров Microsoft отдельно указывает несколько возможностей, которые 26H2 включает по умолчанию. Среди них — резервное копирование настроек Windows, действия для отдельных приложений на панели задач и некоторые изменения Проводника.

Для домашнего пользователя картина проще.

Он, скорее всего, заметит не «новую Windows», а продолжение постепенных изменений, которые уже появляются в Windows 11.

И это, на мой взгляд, главный смысл 26H2.


## Microsoft превращает ежегодный релиз в точку отсчёта

Мне такой подход кажется логичным.

Ежегодное обновление Windows больше не обязано содержать все изменения за один раз.

Представим старую модель.

Microsoft готовит десятки функций. Год ждёт релиза. Потом выпускает новую версию. Пользователь получает большой пакет изменений.

Новая модель работает иначе.

Функция готова — Microsoft постепенно распространяет её через обновления.

Прошло несколько месяцев — появляется следующая версия Windows.

Такой подход снижает разрыв между разработкой функции и её появлением у пользователей.

Но есть и обратная сторона.

Теперь сложнее определить, **какая именно функция относится к конкретной версии Windows**.

Пользователь может получить изменение ещё на 25H2, а затем установить 26H2 и решить, что это и была новая функция 26H2.

С технической точки зрения всё немного сложнее.


## Нужно ли устанавливать 26H2 прямо сейчас

Если компьютер нужен для работы, я бы не спешил.

Release Preview — это уже поздняя стадия тестирования, но это всё ещё программа Windows Insider.

Microsoft предлагает участникам Release Preview установить 26H2 через Windows Update. Для этого компьютер должен соответствовать требованиям Windows 11, а пользователь должен находиться в соответствующем канале Insider.

На основном рабочем компьютере я предпочитаю дождаться стабильного выпуска.

Причина простая: если новая функция не нужна сегодня, нет смысла первым проверять её совместимость с драйверами, программами и корпоративной инфраструктурой.

А вот на тестовом компьютере 26H2 уже представляет интерес.

Особенно если хочется заранее проверить совместимость программ и оборудования. Инструкция по чистой установке 26H2 на неподдерживаемое оборудование — [в отдельном гайде](https://trick32.ru/articles/windows-11-26h2-chistaya-ustanovka-nepodderzhivaemoe-oborudovanie/).


## А что будет с Windows 11 24H2

Вот здесь ситуация интереснее.

Для Home и Pro поддержка Windows 11 24H2 заканчивается **13 октября 2026 года**. Для Enterprise и Education срок заканчивается **12 октября 2027 года**. Эти даты подтверждает Microsoft.

То есть пользователям 24H2 Home и Pro в ближайшие месяцы действительно придётся думать о переходе на более новую версию.

Но это не означает, что нужно устанавливать именно Release Preview 26H2.

Пока 26H2 находится на этапе предварительного тестирования, стабильная система остаётся более разумным выбором для обычного ПК.

К тому же Microsoft уже поддерживает Windows 11 25H2, а для неё установлен отдельный жизненный цикл. Home и Pro получают обновления до октября 2027 года.

Поэтому у владельца 24H2 есть выбор.

Можно дождаться стабильной 26H2.

Можно перейти на 25H2, если обновление уже доступно для конкретного компьютера.

А вот устанавливать Insider Preview только потому, что номер версии стал выше, смысла нет.


## Что будет с ISO

Microsoft сообщила, что ISO Windows 11 26H2 появятся на странице загрузок Windows Insider в ближайшее время.

На этапе Release Preview это особенно полезно для тестирования.

Можно проверить:

– установку Windows с нуля;

– обновление существующей системы;

– работу драйверов;

– совместимость программ;

– корпоративные политики;

– сценарии восстановления.

Если нужно поставить 26H2 с нуля на несовместимое с TPM 2.0 оборудование, есть [отдельная инструкция по чистой установке](https://trick32.ru/articles/windows-11-26h2-chistaya-ustanovka-nepodderzhivaemoe-oborudovanie/).

Для обычного домашнего компьютера ISO из Insider Program пока не даёт особых преимуществ.


## Главное изменение находится не в интерфейсе

Windows 11 26H2 интересна не количеством новых кнопок.

Она показывает, куда Microsoft ведёт саму Windows.

Новые функции теперь не обязательно ждать до следующего ежегодного релиза. Они могут приходить через обычные накопительные обновления.

А 26H2 становится очередной версией в этой системе.

Поэтому фраза «вышла новая Windows» здесь немного вводит в заблуждение.

Правильнее сказать: **Microsoft готовит следующую ежегодную версию Windows 11, но большая часть её платформы уже развивается внутри существующей ветки обслуживания.**

Для пользователя это означает более плавные переходы между версиями.

Для системного администратора — меньше смысла ориентироваться только на номер версии и больше необходимости следить за конкретными обновлениями и политиками.


## Что делать сейчас

Если у вас обычный домашний ПК на Windows 11 25H2 — я бы ничего специально не делал. Пользуйтесь системой и устанавливайте обычные обновления.

Если стоит 24H2 Home или Pro — держите в голове дату **13 октября 2026 года**. До неё ещё есть время подготовиться к переходу.

Если у вас тестовый компьютер — Release Preview уже можно использовать для проверки 26H2.

А вот переводить основной рабочий компьютер на Insider ради одной цифры «26H2» я бы не стал.

Главный вывод простой: **Windows 11 26H2 — это не новая Windows с нуля. Это следующая ступень той модели обновлений, которую Microsoft уже несколько лет постепенно строит.**

И чем дальше, тем меньше ежегодный релиз похож на старое доброе «поставили новую Windows — и всё поменялось».
