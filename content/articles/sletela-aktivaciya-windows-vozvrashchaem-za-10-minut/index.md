Вчера Windows была активирована. Сегодня в правом нижнем углу появился водяной знак: «Активируйте Windows». Компьютер тот же, документы на месте, обновлений вы не запускали.

Первое желание понятное: найти активатор, запустить и забыть. Не спешите. Сначала выясните, что именно пропало: лицензия, связь с сервером или соответствие редакции. От этого зависит решение.

## Windows вас не узнала. Проверяем

Откройте **Параметры → Система → Активация**. Прочитайте сообщение вверху страницы.

Если там написано **«Windows активирована с помощью цифровой лицензии»**, с активацией всё в порядке. Вариант **«...связанной с учётной записью Microsoft»** означает, что лицензия дополнительно привязана к аккаунту.

Если система пишет **«Срок действия Windows истекает»** и показывает дату, перед вами KMS. Если видите **«Windows не активирована»**, рядом будет код ошибки. Он нужен для диагностики.

Есть способ проверить статус без похода по настройкам. Нажмите Win+R, введите:

```
slmgr.vbs /xpr
```

Откроется окно с датой окончания активации. Для бессрочной лицензии Windows так и напишет. Подробности смотрите второй командой:

```
slmgr.vbs /dlv
```

В поле **Description** ищите канал лицензии: `RETAIL`, `OEM` или `VOLUME_KMS`. Это не три разных способа починить Windows. Это подсказка, где искать причину.

## Три обычные истории. Узнайте свою

### После переустановки стоит не та редакция

На ноутбуке была Home. После переустановки кто-то поставил Pro. Система запускается, программы работают, а лицензия не подходит: ключ Home не активирует Pro.

Проверьте редакцию на странице **Активация**. Если там не та версия, не вводите ключ наугад. Сначала установите редакцию, для которой куплена лицензия.

### Закончился KMS

Windows могла работать через корпоративный KMS. Такая активация рассчитана на компьютер, который время от времени связывается с сервером организации. Срок действия: 180 дней. По умолчанию клиент пытается продлевать его каждые семь дней.

Если систему активировали через стороннюю программу, сервер мог исчезнуть, а сеть организации вам недоступна. Прошло полгода. Продление не состоялось, и Windows снова просит активацию. Код `0xC004F074` означает, что KMS не удалось найти.

Это не тот случай, когда помогает ещё один запуск того же активатора. Нужен рабочий корпоративный сервер или собственная лицензия. Почему KMS Auto не превращает Windows в «лицензионную навсегда», я разбирал в статье [про KMS Auto для Windows 10 и 11](/articles/kms-auto-windows-10-11-staryj-sposob-aktivacii/).

### Ключ оказался неподходящим

Ключ из письма, коробки или аккаунта можно ввести снова. А вот ключ с сомнительного маркетплейса способен сначала пройти проверку, а позже перестать работать: его уже использовали, он относится к организации или его заблокировали.

Проверяйте код, а не догадки:

- `0x803FA067`: Windows не нашла цифровую лицензию для этого устройства, например после серьёзной смены оборудования.
- `0xC004F074`: не найден сервер KMS.
- `0xC004C003`: ключ заблокирован или недействителен.
- `0xC004F034`: ключ недействителен или предназначен для другой редакции.

## Чиним за пять шагов

Теперь можно переходить к действиям. Делайте их по порядку: сначала проверка, потом ввод ключа.

**Шаг 1. Сверьте редакцию.** На странице **Параметры → Система → Активация** найдите Home, Pro или Enterprise. Сравните её с лицензией. Home и Pro — не одно и то же. Если поставили не ту редакцию, [переустановите правильную](/articles/obnovit-windows-10-do-windows-11-2026-cherez-parametry-i-iso/). Другой ключ не исправит несовпадение редакций.

**Шаг 2. Проверьте ключ в прошивке.** Если Windows шла вместе с ноутбуком, OEM-ключ мог попасть в UEFI. Откройте PowerShell и выполните:

```powershell
(Get-CimInstance -ClassName SoftwareLicensingService).OA3xOriginalProductKey
```

Появилась строка из 25 символов. Попробуйте этот ключ в **Активация → Изменить ключ продукта**. Пустой результат означает, что в прошивке нет OEM-ключа. Это не доказывает, что лицензии нет: она могла быть цифровой.

**Шаг 3. Введите свой ключ.** Ищите его в письме о покупке, на карточке или в аккаунте магазина. Ввести ключ можно через **Изменить ключ продукта**.

Есть и командный способ. Откройте командную строку от имени администратора:

```
slmgr.vbs /ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
slmgr.vbs /ato
```

`/ipk` устанавливает ключ. `/ato` просит Windows активироваться. Если открыть командную строку без прав администратора, `/ipk` может завершиться ошибкой доступа. Код после `/ato` сопоставьте со списком выше.

**Шаг 4. Верните цифровую лицензию после смены оборудования.** Средство устранения неполадок появляется на странице **Активация**, когда Windows не активирована. Подключитесь к интернету, войдите в аккаунт Microsoft и выберите пункт **«На этом устройстве недавно было изменено оборудование»**.

Затем выберите компьютер из списка, поставьте отметку **«Это устройство, которое я использую сейчас»** и нажмите **«Активировать»**. Этот способ работает, если цифровая лицензия была связана с тем же аккаунтом.

Чтобы проверить список устройств, откройте `account.microsoft.com/devices`. Но наличие компьютера в списке само по себе не заменяет привязку лицензии: важен статус на странице **Активация**.

**Шаг 5. Уберите помехи для активации.** Если ключ правильный, редакция совпадает, но `/ato` не проходит, проверьте сеть. На время отключите VPN и корпоративный прокси. Затем повторите команду.

Если после этого активация прошла, проблема была в соединении с сервером. Если нет, вернитесь к коду ошибки: он важнее догадок про «сломавшуюся Windows».

## Когда сама не вернётся

После замены материнской платы Windows может перестать находить цифровую лицензию устройства. Если аккаунт Microsoft не был связан с лицензией заранее, средство устранения неполадок не сможет подтвердить право на перенос. Проверьте старый ключ или обратитесь в поддержку Microsoft.

Enterprise с KMS чужой организации тоже не активируется домашним ключом. Такая редакция рассчитана на корпоративную схему. Нужна лицензия, которая подходит именно этой редакции, либо переустановка своей редакции Windows.

Если систему запускал активатор, а его KMS-сервер больше недоступен, повторная команда не поможет. Траблшутер тоже не создаёт новую лицензию. Нужен свой ключ, цифровая лицензия или корпоративный сервер.

Если ключ купили за 300 рублей и продавец исчез, сначала проверьте код и происхождение ключа. Не скачивайте поверх него ещё один активатор. О рисках таких схем написал в статье [про KMS Auto](/articles/kms-auto-windows-10-11-staryj-sposob-aktivacii/).

## Нужна помощь?

Если вы не понимаете, какая редакция установлена, ключ не принимается, а средство устранения неполадок не помогает, можно разобрать компьютер удалённо. Сначала проверю редакцию, канал лицензии и код ошибки. Потом скажу, что можно восстановить, а что потребует новой лицензии.

Нажмите кнопку «💬 Написать в чате» справа внизу.

## Итог

Начинайте не с активатора. Откройте **Активация**, определите редакцию, посмотрите код и канал лицензии. После этого станет понятно, что делать:

- не та редакция: установить правильную;
- есть свой ключ: ввести его;
- была смена оборудования: запустить средство устранения неполадок;
- `VOLUME_KMS` и `0xC004F074`: искать корпоративный сервер или переходить на свою лицензию;
- `/ato` не проходит: проверить сеть и код ошибки.

У активации Windows нет универсальной кнопки «починить». Зато есть понятная последовательность: сначала выяснить причину, потом выбрать способ восстановления.
