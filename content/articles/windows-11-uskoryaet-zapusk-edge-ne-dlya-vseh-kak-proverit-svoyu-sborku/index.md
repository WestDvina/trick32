Обновление Edge само по себе не включает ускоренный запуск. Нужны Windows 11 25H2, 26H1 или 26H2, необязательное обновление KB5127936 (для 26H1 — KB5127653) и Edge версии 150 или новее. В списке поддерживаемых версий 24H2 нет.

Microsoft заявляет ускорение на 15% для большинства пользователей и до 33% при тяжёлой многозадачности. Это данные Microsoft, замер при уже запущенном Edge; независимого теста нет. Функция ускоряет повторный, «тёплый» запуск, а не холодный старт браузера после полного закрытия.

## Что именно ускорили в Edge

Когда Edge уже работает, Windows может открыть его повторно — например, по ссылке или с панели задач. Без Accelerated App Launch система запускает промежуточный процесс: тот ищет открытый браузер и передаёт ему запрос. С функцией Edge заранее регистрируется в Windows, поэтому при следующем обращении Windows уведомляет работающий процесс напрямую. Так сокращается задержка между нажатием и появлением окна.

Поддерживаются запуск из меню «Пуск», с панели задач и открытие ссылок, которые по умолчанию ведут в Edge. Это не ускорение любого запуска: функция рассчитана на ситуацию, когда браузер уже открыт или работает в фоне. Если Edge полностью завершён, сравнивать нужно именно повторный запуск с «холодным». Разница может быть почти незаметна на только что загруженном компьютере и проявляться сильнее под нагрузкой.

Проверить эффект можно без секундомера: оставьте Edge запущенным, закройте его окно, затем откройте ссылку или запустите браузер с панели задач. После этого полностью закройте Edge и повторите тот же сценарий. Не ждите одинаковой разницы в каждом случае. Microsoft указывает, что результат зависит от уже работающего браузера. Если [медленно запускаются программы в Windows](/articles/windows-11-programmy-dolgo-zapuskayutsya-smart-app-control/), причина может быть общей для системы, а не связанной только с Edge.

Открытие PDF-файлов и другие точки входа Microsoft пока называет планами, а сам механизм обещает передать в Chromium, чтобы ускорением могли воспользоваться другие браузеры на его основе, но сроков ни для одного из этих сценариев не называет.

## Версия Windows и Edge: проверка тремя командами

Три команды закрывают вопрос.

Откройте PowerShell и выполните первую команду. Она покажет редакцию Windows, версию выпуска, номер базовой сборки и ревизию UBR. Например, строка `26200` вместе с `UBR 9818` означает сборку `26200.9818`; сравнивать нужно всю пару, а не только первые цифры.

```powershell
Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion' |
  Select-Object ProductName, DisplayVersion, CurrentBuild, UBR
```

Вторая команда выведет версию установленного Edge. Здесь проверяется файл браузера `msedge.exe`, потому что Edge — Win32-приложение, а не пакет Appx.

```powershell
(Get-Item "${env:ProgramFiles(x86)}\Microsoft\Edge\Application\msedge.exe").VersionInfo.ProductVersion
```

Третья команда проверит наличие октябрьского пакета. Для 25H2 и 26H2 ищите KB5127936, для 26H1 — KB5127653.

```powershell
Get-HotFix -Id KB5127936, KB5127653 -ErrorAction SilentlyContinue
```

Сверьте сборку и номер обновления:

| Версия Windows | CurrentBuild | Целевая сборка после обновления | Пакет |
|---|---:|---:|---|
| 25H2 | 26200 | 26200.9818 | KB5127936 |
| 26H2 | 26300 | 26300.9818 | KB5127936 |
| 26H1 | 28000 | 28000.3365 | KB5127653 |
| 24H2 | 26100 | — | preview-обновлений для 24H2 больше нет |

Если `UBR` равен целевой ревизии или выше, а Edge имеет версию 150+, требования выполнены. Проверьте тёплый запуск. Если `UBR` ниже, установите подходящее необязательное обновление. Для дополнительной проверки пакета можно выполнить команду DISM:

```cmd
DISM /Online /Get-Packages | findstr /i "9818 3365"
```

Версию Edge также можно посмотреть на странице `edge://version`, а сборку Windows — в окне `winver`. Если в ответе первой команды стоит 24H2 и сборка 26100, дальше проверять нечего: с октября 2026 года Microsoft больше не выпускает для 24H2 необязательные preview-обновления, а сама функция в списке поддерживаемых версий 24H2 не значится, поэтому обновление Edge до 150 или новее ничего не изменит.

## Как поставить необязательное обновление

Откройте **Параметры → Центр обновления Windows → Дополнительные параметры → Необязательные обновления** (англ. Settings → Windows Update → Advanced options → Optional updates). Выберите пакет для своей ветки: KB5127936 для Windows 11 25H2 или 26H2, KB5127653 для 26H1. Оба обновления от 28 октября 2026 года имеют тип preview, то есть относятся к необязательным предварительным обновлениям.

После установки перезагрузите компьютер. Перезагрузка обязательна. Затем снова проверьте сборку командой из предыдущего раздела: она должна достичь значения 26200.9818 для 25H2, 26300.9818 для 26H2 или 28000.3365 для 26H1. Если после установки пакет больше не виден в списке необязательных обновлений, ориентируйтесь на UBR и `Get-HotFix`: список показывает только то, что Windows ещё предлагает.

Перед установкой учтите известную проблему, которую KB5127936 документирует: после обновления безопасности от 8 сентября 2026 года некоторые устройства USB Audio Class 1.0 не запускаются, показывают в диспетчере устройств ошибку Code 10 или не выдают звук, а Microsoft на момент публикации решения не опубликовала. Пакет KB5127936 эту проблему не создаёт, но и не устраняет. Сроков решения нет. Если такое аудиоустройство важно для работы, риск стоит взвесить заранее. Обновление KB5127936 также исправляет известную проблему, из-за которой переключатель [Smart App Control](/articles/smart-app-control-ne-vklyuchaetsya-posle-kb5127648-kak-vernut-pereklyuchatel/) мог быть неактивен, но это отдельный эффект того же пакета.

## Если ускорения всё равно нет

- Если Edge ниже версии 150 → откройте `edge://settings/help`, обновите браузер и перезапустите его.
- Если Edge полностью закрыт → запустите его и повторите проверку при открытом или работающем в фоне браузере: холодный старт функция не ускоряет.
- Если UBR ниже целевого → установите пакет для своей версии Windows и перезагрузите компьютер.
- Если обновления нет в списке → проверьте, не приостановлено ли обновление Windows и не управляет ли им WSUS или групповая политика.
- Если пакет уже установлен, но его нет в списке необязательных обновлений → это нормально; проверьте UBR и результат `Get-HotFix`.
- Если пропал звук на USB Audio Class 1.0 → это известная проблема с Code 10 или отсутствием звука после обновления безопасности от 8 сентября 2026. Пакет можно удалить через **Параметры → Центр обновления Windows → Журнал обновлений → Удалить обновления**, но решения Microsoft на момент публикации нет.
- Если установлена Windows 11 24H2 → поможет только переход на 25H2 или 26H2: новый Edge сам по себе функцию в 24H2 не добавит.

Если переход на 26H2 вызывает опасения, заранее проверьте, [как подготовить Windows к обновлению](/articles/windows-11-26h2-kak-izbezhat-problem-pri-obnovlenii/), чтобы снизить вероятность проблем.

## Нужна помощь с проверкой Edge

Помогу сверить версию Windows, сборку и Edge, а также понять, какой пакет нужен именно для вашей ветки. Если ускорение не появилось после обновления, можно проверить результат по UBR и установленному KB.

Также помогу отличить неподдерживаемую 24H2 от ситуации, когда пакет ещё не установлен или Edge не соответствует требованию. Для этого используйте кнопку **«Чат на сайте»**.
