Если посмотреть системные требования Windows 11, можно увидеть цифру 64 ГБ. Из-за неё легко сделать вывод: значит, для Windows достаточно диска на 64 ГБ. На практике это плохая идея.

64 ГБ — минимальный объём накопителя, который Microsoft указывает для устройства с Windows 11. Это не означает, что после установки система будет занимать ровно 64 ГБ или что весь оставшийся объём можно спокойно отдать файлам.

Если выбирать накопитель для компьютера, нужно учитывать саму систему, обновления, временные файлы, файл подкачки, гибернацию и программы.

## Что означает требование 64 ГБ

Microsoft указывает для Windows 11 накопитель объёмом **64 ГБ или больше**. Это минимальное системное требование.

Но Windows не устанавливает себя в виде фиксированного набора файлов размером 64 ГБ.

После установки система создаёт дополнительные файлы. Их размер зависит от конфигурации компьютера и того, как он используется.

Например, место могут занимать:

* файлы Windows;
* компоненты обновлений;
* временные файлы;
* файл подкачки;
* файл гибернации;
* точки восстановления;
* кэш обновлений;
* установленные языковые пакеты;
* дополнительные компоненты Windows.

Поэтому вопрос «сколько весит Windows 11?» не имеет одного правильного ответа.

## Сколько места реально занимает Windows

На чистой установке Windows 11 размер системных файлов может заметно отличаться от компьютера к компьютеру.

На моём опыте смотреть нужно не на размер папки `C:\Windows`, а на **занятое место системным разделом после установки и настройки системы**.

У одного компьютера Windows вместе с системными файлами может занимать несколько десятков гигабайт. У другого — существенно больше.

Причина проста: Windows хранит не только файлы операционной системы.

Например, файл подкачки создаётся для виртуальной памяти. Его размер зависит от объёма оперативной памяти и настроек системы.

Файл гибернации `hiberfil.sys` тоже может занимать заметное место. Особенно если компьютер поддерживает гибернацию и быстрый запуск.

А после нескольких обновлений появляются дополнительные данные, необходимые для обслуживания системы и иногда для отката.

Поэтому цифра «Windows занимает 20, 30 или 40 ГБ» без указания конфигурации компьютера мало что говорит.

## Почему диск на 64 ГБ быстро превращается в проблему

Представим компьютер с накопителем на 64 ГБ.

Даже если Windows после установки оставит некоторое количество свободного пространства, пользователь начинает устанавливать браузер, Office, мессенджеры, архиватор и другие программы.

Появляются документы, фотографии и загрузки.

Windows продолжает получать обновления.

Свободного места становится всё меньше.

И в какой-то момент проблема возникает не потому, что Windows внезапно стала огромной.

Просто накопитель изначально был слишком маленьким для реальной эксплуатации.

Microsoft отдельно предупреждает, что для установки обновлений Windows требуется дополнительное свободное место. Для функциональных обновлений обычно требуется **6–11 ГБ или больше**, а для накопительных обновлений — **2–3 ГБ или больше**.

Причём это не постоянное требование. Размер зависит от состояния конкретного компьютера.

Для некоторых сценариев обновления Windows 11 Microsoft приводит варианты, где может потребоваться около **20 ГБ свободного пространства**. При большом количестве дополнительных компонентов, языков и обновлений потребность может быть ещё выше.

Вот почему ситуация «на диске осталось 7 ГБ, а Windows просит освободить место» вполне реальна.

## А сколько места нужно Windows 10?

У Windows 10 требования ниже.

Для актуальных версий Windows 10 Microsoft указывала накопитель объёмом **32 ГБ или больше**.

Но логика остаётся той же.

32 ГБ — это минимальный порог, а не рекомендация покупать компьютер с SSD на 32 ГБ.

Более того, поддержка Windows 10 завершилась 14 октября 2025 года. Поэтому сегодня при покупке нового компьютера ориентироваться на минимальные требования Windows 10 уже бессмысленно.

## Какой объём SSD я бы выбрал

Если компьютер нужен не только для запуска Windows, я бы не рассматривал накопитель на 64 ГБ.

**128 ГБ** — нижняя граница для очень простой системы.

Такого объёма хватит для Windows, нескольких программ и небольшого количества пользовательских файлов. Но постоянно следить за свободным местом всё равно придётся.

**256 ГБ** — уже нормальный минимальный вариант для обычного домашнего компьютера.

Windows занимает свою часть, программы — свою, а пользователю остаётся достаточно места для документов и других файлов.

**512 ГБ** — мой выбор для основного компьютера, если нет причины экономить каждый гигабайт.

На таком SSD Windows не приходится постоянно «ужимать». Можно поставить программы, хранить рабочие файлы и оставить запас под обновления.

**1 ТБ** имеет смысл, если компьютер используется для игр, монтажа, хранения фотографий, видео или других больших файлов.

При этом важно понимать одну вещь: большой диск не делает Windows легче. Он просто оставляет системе и пользователю больше пространства для работы.

## Как посмотреть, сколько места занимает Windows на вашем компьютере

Самый простой вариант — открыть:

**Параметры → Система → Память.**

Windows покажет распределение занятого места по категориям.

Там можно увидеть, сколько занимают приложения, временные файлы, системные данные и другие категории.

Если хочется разобраться глубже, можно открыть системный диск `C:` и посмотреть его свойства.

Но я бы не советовал оценивать размер Windows только по папке `C:\Windows`.

Например, файл подкачки и файл гибернации находятся в корне системного диска и могут занимать гигабайты.

## Почему свободное место важнее размера самой Windows

При выборе SSD я смотрю не на вопрос «сколько весит Windows», а на другой:

**сколько места останется после установки Windows, программ и моих файлов?**

Это гораздо полезнее.

Допустим, SSD имеет объём 256 ГБ.

После установки Windows и программ остаётся достаточно свободного пространства. Обновления устанавливаются без постоянных предупреждений. Пользователь может хранить документы и не думать о диске каждый вечер.

Теперь представим тот же компьютер с SSD на 64 ГБ.

Формально Windows 11 соответствует системным требованиям. Но запас места настолько маленький, что любая крупная установка или обновление быстро превращается в проблему.

Получается парадокс: компьютер соответствует минимальным требованиям, но пользоваться им нормально уже неудобно.

## Можно ли уменьшить размер Windows?

Да, но здесь легко увлечься.

Windows действительно оставляет временные файлы и старые компоненты. Их можно удалять штатными средствами.

Для этого в Windows 11 есть:

**Параметры → Система → Память → Рекомендации по очистке.**

Также можно использовать встроенную очистку временных файлов.

А вот удалять системные папки вручную ради нескольких гигабайт я бы не стал.

Особенно опасны советы из серии «удалите эту папку в WinSxS» или «полностью отключите обновления, чтобы освободить место».

Несколько гигабайт экономии не стоят проблем с обслуживанием системы.

## Мой практический вывод

Если вопрос звучит как «сколько места занимает Windows 11», ответ такой:

**сама операционная система — это только часть расходов на дисковое пространство.**

Microsoft требует для Windows 11 накопитель от 64 ГБ, но это минимальное системное требование, а не комфортный объём SSD.

Для реального компьютера я бы ориентировался минимум на **256 ГБ**, а для основного ПК — на **512 ГБ**.

И ещё один совет.

Не ждите, пока свободное место на диске закончится полностью. Windows нужны гигабайты свободного пространства не только для работы пользователя, но и для обновлений.

Если на системном SSD осталось несколько гигабайт, проблема уже появилась. Лучше решить её заранее — удалить ненужные файлы, перенести большие данные или увеличить накопитель.
