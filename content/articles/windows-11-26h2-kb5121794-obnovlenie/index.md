Microsoft начала распространение Windows 11 26H2 через канал Release Preview. Для пользователей Windows 11 24H2 и 25H2 есть интересный вариант обновления: пакет включения функций KB5121794. Он переводит систему на Windows 11 26H2 без установки из ISO-образа и без удаления программ и файлов.

Но есть нюанс. На 28 августа 2026 года 26H2 ещё проходит финальное тестирование в Release Preview. Microsoft называет сборку 26300.9278 предварительной и обещает общий выпуск позже в этом году. Поэтому устанавливать её сейчас стоит тем, кто понимает разницу между Release Preview и обычным стабильным каналом.

## Что такое KB5121794

KB5121794 это Enablement Package, или пакет включения функций. Название звучит так, будто Windows сейчас будет скачивать несколько гигабайт, но сам пакет занимает всего около 174 КБ.

Причина проста: Windows 11 24H2, 25H2 и 26H2 используют общую ветку обслуживания. Microsoft постепенно доставляет новые компоненты через обычные накопительные обновления, а часть изменений остаётся выключенной.

Enablement Package включает нужные компоненты, и система переходит на новую версию. Microsoft официально подтверждает эту схему для Windows 11 26H2: в Release Preview новая версия имеет номер сборки **26300.9278**.

То есть переход выглядит так:

**Windows 11 24H2 → 26H2**

или

**Windows 11 25H2 → 26H2**

При этом не требуется форматировать диск или запускать установку Windows с нуля.

## Кто может установить 26H2 через KB5121794

Пакет рассчитан на системы с Windows 11:

* 24H2;
* 25H2.

Но одной версии Windows недостаточно: перед установкой KB5121794 система должна иметь актуальную версию накопительного обновления **KB5120998**.

После него система должна иметь один из двух билдов:

* **Windows 11 24H2: 26100.9278**;
* **Windows 11 25H2: 26200.9278**.

Это подтверждает сама Microsoft. Обновление KB5120998 от 27 августа 2026 года выпускается для Windows 11 24H2 и 25H2.

Проверить свою сборку можно командой:

`Win + R` → `winver`

Если там стоит 26100.9278 или 26200.9278, можно переходить к следующему шагу.

## Сначала устанавливаем KB5120998

Если `winver` показывает старую сборку, сначала установите KB5120998.

Microsoft разместил его в Microsoft Update Catalog.

[Открыть KB5120998 в Microsoft Update Catalog](https://www.catalog.update.microsoft.com/Search.aspx?q=KB5120998)

Выбирайте пакет под свою архитектуру.

Для большинства компьютеров Intel и AMD это:

**2026-08 Cumulative Update Preview for Windows 11, version 24H2 for x64-based Systems (KB5120998)**

или

**2026-08 Cumulative Update Preview for Windows 11, version 25H2 for x64-based Systems (KB5120998)**.

После установки потребуется перезагрузка.

Затем снова запустите `winver`.

Должно получиться:

**26100.9278** для 24H2.

или

**26200.9278** для 25H2.

## Установка KB5121794

Если необходимая сборка уже установлена, всё просто.

1. Скачайте MSU-файл KB5121794.
2. Запустите его двойным щелчком.
3. Подтвердите установку.
4. Дождитесь окончания.
5. Перезагрузите компьютер.

После перезагрузки снова выполните:

`Win + R` → `winver`

Теперь должна отображаться:

**Windows 11, версия 26H2**

и сборка:

**26300.9278**.

Сам процесс занимает гораздо меньше времени, чем переустановка через ISO. Именно в этом смысл Enablement Package: большая часть необходимых компонентов уже есть в системе.

## Что произойдёт с программами и файлами

При обычном переходе через KB5121794 это не чистая установка Windows: документы, фотографии, программы, настройки и учётные записи остаются в системе.

По сути, Windows меняет версию и включает необходимые функции. Но резервную копию перед крупным обновлением я всё равно сделал бы.

Причина не в самом KB5121794, а в том, что проблема может возникнуть не только из-за обновления: старый драйвер, сторонний антивирус, повреждённый системный компонент или неудачная конфигурация могут превратить обычную перезагрузку в квест.

## А если у меня Windows 10 или 23H2?

Здесь KB5121794 не поможет: пакет предназначен для перехода с Windows 11 24H2 и 25H2, а эти версии живут на общей ветке обслуживания с 26H2.

Если у вас:

**Windows 10 → 26H2**

или

**Windows 11 23H2 → 26H2**

нужен другой путь: установка через ISO.

Это принципиальная разница: Enablement Package не универсальный установщик новой Windows. Он скорее похож на переключатель версии внутри уже подготовленной системы.

## А что с TPM 2.0 и Secure Boot?

KB5121794 не превращает неподдерживаемый компьютер в официально совместимый: если компьютер не соответствует требованиям Windows 11, не стоит воспринимать маленький размер пакета как способ обхода требований. Для обычной установки Microsoft по-прежнему ориентируется на поддерживаемое оборудование.

Если вы ранее устанавливали Windows 11 на [неподдерживаемый ПК](https://trick32.ru/articles/windows-11-26h2-chistaya-ustanovka-nepodderzhivaemoe-oborudovanie/) с помощью Rufus, модифицированного ISO или других способов, ситуация отдельная. Сам факт установки KB5121794 не означает, что Microsoft теперь официально поддерживает такую конфигурацию.

## Стоит ли переходить на 26H2 прямо сейчас

Вот здесь я бы не торопился: Microsoft выпустила [26H2 в Release Preview](https://trick32.ru/articles/windows-11-26h2-release-preview/) **27 августа 2026 года**. Это уже поздняя стадия тестирования, но всё ещё программа Windows Insider. Общедоступный выпуск запланирован позже в 2026 году.

Для тестового компьютера: почему бы и нет. А вот на рабочем, от которого зависит работа, бухгалтерия, серверное ПО или старые программы, я бы подождал публичного релиза.

Тем более что переход с 24H2 на 26H2 сейчас не даёт такого выигрыша, ради которого обязательно нужно рисковать стабильностью. Есть ещё один аргумент: **Windows 11 24H2 Home и Pro перестанут получать обновления 13 октября 2026 года**, поэтому владельцам 24H2 всё равно придётся переходить на более новую версию.

Но делать это можно спокойно: после выхода 26H2 в обычный канал.

## Что нового в 26H2

Microsoft описывает 26H2 не как полностью новую Windows: это продолжение той же ветки, которая объединяет 24H2, 25H2 и 26H2. Многие [функции 26H2](https://trick32.ru/articles/skrytye-funkcii-windows-11-26h2/) уже постепенно появлялись в предыдущих версиях через ежемесячные обновления.

Для коммерческих устройств Microsoft отдельно выделяет:

* резервное копирование настроек Windows;
* действия для отдельных приложений из панели задач;
* новые возможности Проводника.

Поэтому переход на 26H2 это не история про «совсем новую Windows»: скорее Microsoft продолжает собирать уже существующую Windows в следующую версию.

## Мой вывод

KB5121794: интересный способ перейти с Windows 11 24H2 или 25H2 на 26H2 без полноценной переустановки.

Но сейчас есть важное слово: **Release Preview**. На 28 августа 2026 года Windows 11 26H2 ещё не стала обычным публичным релизом: Microsoft сама говорит, что общий выпуск состоится позже в этом году.

Поэтому я бы разделил пользователей на две группы: если вы тестируете Windows и хотите попробовать 26H2 уже сейчас, KB5121794 позволяет сделать это быстро, а вот на рабочем компьютере я бы дождался публичного выпуска.

А сам механизм Microsoft выбрала разумный. Не нужно скачивать десятигигабайтный ISO ради смены номера версии: если 24H2 и 25H2 уже живут на общей ветке обслуживания, достаточно небольшого пакета, который включает нужные изменения.

И это, пожалуй, самый интересный момент в Windows 11 26H2.
