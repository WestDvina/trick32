Windows 10 Pro показывает **0x8007232B**, и активация не проходит: система с ключом KMS-клиента ищет KMS-хост, которого не находит. Проверим канал лицензии и заменим KMS-ключ на законный. Если онлайн-активация не сработает, останется портал активации продуктов Microsoft — телефонный звонок больше не используется.

В сообщении **0x8007232B** зашифровано простое «DNS name does not exist». Это не общий диагноз «сломался интернет»: KMS-клиент не нашёл в DNS запись, по которой Windows обнаруживает хост управления ключами. Подробности этого случая собраны в [разборе ошибки активации Windows 10 Pro](https://trick32.ru/articles/oshibka-0x8007232b-pri-aktivatsii-windows-10-pro/).

## Сначала выясните, какой ключ установлен

Запустите проверку лицензии — команда покажет поле **Description**. Значение **VOLUME_KMSCLIENT** означает, что Windows настроена как KMS-клиент. Такой ключ ожидает корпоративный KMS-хост; сам по себе он не является розничной лицензией и не активирует розничную редакцию.

> **slmgr.vbs /dlv**

Сверьте и состояние активации:

> **slmgr.vbs /xpr**

Эта проверка показывает, истекает ли активация; для розничной лицензии и MAK-ключа она бессрочная. Если на личном компьютере обнаружен **VOLUME_KMSCLIENT**, а корпоративной сети нет, переходите на законный розничный или MAK-ключ, подходящий для установленной Windows 10 Pro.

Ключ можно поменять через **Параметры → Обновление и безопасность → Активация → Изменить ключ продукта**. Либо в командной строке с правами администратора укажите ключ командой установки, затем запустите онлайн-активацию:

> **slmgr.vbs /ipk** — укажите после команды свой законный ключ
>
> **slmgr.vbs /ato**

Не подставляйте случайный ключ: он должен быть законным и соответствовать выпуску Windows. Если ключ есть, но онлайн-активация не проходит, откройте **Параметры → Обновление и безопасность → Активация → Активировать по телефону**. Когда этого пункта нет, нажмите Win+R и введите:

> **slui 4**

Окно покажет Installation ID. Звонить по номеру не нужно: Microsoft отключила телефонную активацию и перевела офлайн-сценарий на портал активации продуктов. Откройте портал с другого устройства, войдите в учётную запись Microsoft, введите Installation ID и получите Confirmation ID. Для России и Беларуси отдельного телефонного пути тоже нет — остаётся портал. Если подходящего ключа нет, активация не завершится: портал не заменяет лицензию.

## Если активация всё ещё не проходит

- **Если новый ключ отклонён**, проверьте, что он законный и предназначен именно для установленного выпуска Windows 10. Не повторяйте попытки с неподходящим ключом: он не заменит нужную лицензию. Если ошибка сохраняется, сохраните подробные сведения о лицензии и обратитесь в поддержку Microsoft.
- **Если это рабочий компьютер**, не меняйте ключ самостоятельно: KMS может быть штатным способом активации организации. Администратору нужно проверить DNS-запись **_vlmcs._tcp** и доступность **TCP 1688** между компьютером и KMS-хостом.

Если личный компьютер просит KMS, а рабочий — не находит хост, код одинаковый, но действия разные: в первом случае нужен подходящий личный способ лицензирования, во втором — проверка корпоративной сети.
