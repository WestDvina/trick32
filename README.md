# trick32.ru

Статьи сайта — Hugo в `content/articles/`, деплой — GitHub Actions → GitHub Pages при push
в `main`. Отдельный сервер не нужен, специальный софт на рабочей машине тоже.

## Выпустить статью с Windows или macOS

1. `git pull`, затем новая папка `content/articles/<slug>/index.md` (slug — латиница через дефис).
2. Frontmatter:

```yaml
---
title: "Заголовок статьи"
date: "2026-10-13T10:00:00+03:00"
description: "Один абзац для поиска и соцсетей."
categories: ["windows"]
tags: ["windows-11", "обновление"]
draft: false
---
```

3. Закоммитить и запушить в `main`.

Остальное делает сборка: рисует OG-карточку `/og/<slug>.jpg`, сама дописывает
`images: ["/og/<slug>.jpg"]` во frontmatter и публикует страницу. Рисовать картинку
руками не нужно. Если карточку нарисовать не удалось или у опубликованной статьи её нет —
сборка падает с именем статьи, а не публикует страницу без превью.

Хук карточки (3–5 слов крупным текстом, не весь заголовок) — по желанию, в
`tools/og-image/hooks.json`. Без него хук собирается из заголовка.

## Что учесть на Windows

- Кроме git ничего ставить не обязательно: правки, коммит, push.
- Файлы — UTF-8 без BOM, переводы строк LF. Это задают `.editorconfig` и `.gitattributes`,
  поэтому один и тот же файл не «переписывается» целиком при переходе между машинами.
- Дата статьи в будущем (по московскому времени) означает, что Hugo её не публикует —
  ставьте дату не позже текущей.
- Предпросмотр (необязательно): Hugo extended 0.164.0 (`winget install Hugo.Hugo.Extended`),
  потом `hugo server` в корне репозитория.

## Локально не обязательное

Постеры (`poster.png` / `poster.webp` в папках статей) сайт не использует — коммитить их
не нужно. Карточку локально можно посмотреть командой
`python3 tools/og-image/generate_og.py` (`tools/og-image/README.md`), но на сервере сборка
сделает это сама.
